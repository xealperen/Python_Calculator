# Simple CLI Calculator in Python

A clean, modular command-line calculator built with Python. This project serves as my first hands-on system implemented while learning fundamental Python programming concepts, modular function design, and control flows.

---

## Features

* **Basic Arithmetic Operations**: Supports addition, subtraction, multiplication, and division.
* **Error Handling**: Implements explicit exception raising (`ValueError`) to handle division by zero safely.
* **CLI Interface**: Interactive menu system driven by user input for operation selection.
* **Execution Loop**: Uses a continuous execution flow allowing multiple calculations in a single session.

---

## Functions Breakdown

* `add(a, b)`: Returns the sum of two numbers.
* `subtract(a, b)`: Returns the difference between two numbers.
* `multiply(a, b)`: Returns the product of two numbers.
* `divide(a, b)`: Performs division; raises a `ValueError` if the denominator is zero.
* `exit()`: Safely terminates the script execution.
* `main()`: Handles user menu interface, input parsing, and conditional routing.
